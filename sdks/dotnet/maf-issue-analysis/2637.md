# Issue #2637 — parentMessageId is serialized as null

- Repo: microsoft/agent-framework · [issue #2637](https://github.com/microsoft/agent-framework/issues/2637)
- Category: **Integration-pkg — already fixed/covered**

## Summary
The issue reports that `TOOL_CALL_START` events serialize `"parentMessageId": null`, which violates the AG-UI TypeScript schema where `parentMessageId` is optional but not nullable.

## Fix in our SDK
`src\AGUI.Abstractions\Events\ToolCallStartEvent.cs:14-16` marks `ParentMessageId` with `JsonIgnoreCondition.WhenWritingNull`:

```csharp
[JsonPropertyName("parentMessageId")]
[JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
public string? ParentMessageId { get; set; }
```

## Validating test
Added (pending central run): `tests\AGUI.Abstractions.UnitTests\MafIssueFixedTests_2637.cs:8-20`, method `ToolCallStartEvent_Serialization_OmitsParentMessageId_WhenNull`, serializes a `ToolCallStartEvent` without a parent and asserts the `parentMessageId` property is absent.

## Notes
MAF inherits the client-schema-compatible wire shape by using `AGUI.Abstractions.ToolCallStartEvent` and the source-generated AG-UI serializer context.
