# Issue #3033 — .NET DevUI client fails on fractional created_at from Python server

- Repo: microsoft/agent-framework · [issue #3033](https://github.com/microsoft/agent-framework/issues/3033)
- Category: **AF-specific** — proposal for once MAF consumes our packages

## Summary
A .NET MAF client calls a Python DevUI Responses REST API and fails deserializing a fractional Unix `created_at` value into a .NET `DateTimeOffset`. The failing shape is the OpenAI/DevUI Responses JSON model, not AG-UI SSE.

## What our packages already provide
- `AGUI.Client` speaks the AG-UI protocol: `IAGUITransport.SendAsync` sends `RunAgentInput` and returns `BaseEvent` streams (`sdks/dotnet/src/AGUI.Client/IAGUITransport.cs:10`, `sdks/dotnet/src/AGUI.Client/IAGUITransport.cs:18`).
- The HTTP transport posts `RunAgentInput` using the AG-UI serializer and parses SSE data as `BaseEvent` (`sdks/dotnet/src/AGUI.Client/AGUIHttpTransport.cs:33`, `sdks/dotnet/src/AGUI.Client/AGUIHttpTransport.cs:35`, `sdks/dotnet/src/AGUI.Client/AGUIHttpTransport.cs:63`).
- The AG-UI client builds AG-UI `RunAgentInput` from MEAI messages/options; it does not deserialize OpenAI Responses `created_at` fields (`sdks/dotnet/src/AGUI.Client/AGUIChatClient.cs:355`, `sdks/dotnet/src/AGUI.Client/AGUIChatClient.cs:362`).

## What remains MAF-side
MAF owns the DevUI/OpenAI Responses client models and converters, including the `created_at` property type. Our AG-UI SDK does not parse Python DevUI Responses JSON or define the OpenAI `Response` model.

## Proposal (once MAF consumes our packages)
1. In MAF's Responses REST client model, add a tolerant converter for `created_at` accepting integer Unix seconds and fractional Unix seconds.
2. Preserve sub-second precision when converting to `DateTimeOffset` instead of truncating unless protocol compatibility requires an integer.
3. Add interop tests using a Python DevUI response sample with `created_at: 1766440374.769623`.
4. Document that callers using AG-UI endpoints can avoid this Responses-model path by using `AGUIChatClient`/`IAGUITransport` against AG-UI SSE endpoints.
