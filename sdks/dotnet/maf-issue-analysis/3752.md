# Issue #3752 — [AG-UI] Usage and Annotations are not present

- Repo: microsoft/agent-framework · [issue #3752](https://github.com/microsoft/agent-framework/issues/3752)
- Related: #3520, #3684 (usage); annotations tracked here too
- Category: **Integration-pkg — by design (extensibility), not a default mapping**

## Summary
Two items: (1) token **usage** is not surfaced by default; (2) message **annotations**
(e.g. citations) are not propagated.

## Resolution — by design, via extensibility
Neither token usage nor MEAI annotations are AG-UI protocol concepts, so per our guiding
principle both are surfaced through extensibility rather than a default mapping. The
**preferred** path is a delegating `IChatClient`/`AIAgent`; a content mapper is a secondary
seam for framework integrators:
- **Usage** — wrap the `IChatClient`/`AIAgent` to emit a `CustomEvent`/`RawEvent` via
  `ChatResponseUpdate.RawRepresentation` (as `Step06_RawEvents` `UsageRawEventsChatClient`
  does). Framework integrators can alternatively use `AGUIStreamOptions.MapContent(...)`.
  See [3520.md](3520.md).
- **Annotations** — `TextContent.Annotations` (MEAI) have no AG-UI protocol slot, so likewise
  surface them as a `CustomEvent`/`RawEvent` via a delegating client/agent.

## Validation
By design — no dedicated test (per our rule). Usage snippet in [3520.md](3520.md); the
wrapping-client path is exercised by the Step06 sample tests. Annotations use the same
delegating-client mechanism.

## Proposed step
No framework change — document the extensibility recipes for usage and annotations.
