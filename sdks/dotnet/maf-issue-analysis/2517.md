# Issue #2517 — Thread persistence does not work by default in MapAGUI

- Repo: microsoft/agent-framework · [issue #2517](https://github.com/microsoft/agent-framework/issues/2517)
- Category: **AF-specific** — proposal for once MAF consumes our packages

## Summary

The issue reports that MAF `MapAGUI` calls `AIAgent.RunStreamingAsync(...)` without an `AgentThread`, so configured `ChatMessageStoreFactory` instances create a fresh store for each request. Although AG-UI sends a stable thread id, MAF does not use it to restore or persist the server-side agent thread by default.

## What our packages already provide

`RunAgentInput.ThreadId` is public (`src\AGUI.Abstractions\Context\RunAgentInput.cs:13`-`17`). `ToChatRequestContext` preserves the full input on the returned context (`src\AGUI.Hosting.AspNetCore\RunAgentInputExtensions.cs:101`-`108`) and stashes it in `ChatOptions.AdditionalProperties[AGUIConstants.RunAgentInputKey]` (`src\AGUI.Hosting.AspNetCore\RunAgentInputExtensions.cs:91`-`96`). `AGUIConstants.RunAgentInputKey` is public for delegating clients/tools that only receive `ChatOptions` (`src\AGUI.Hosting.AspNetCore\AGUIConstants.cs:8`-`16`).

## What remains MAF-side

Creating, resolving, and passing `AgentThread` instances is an Agent Framework hosting/session-store responsibility. Our SDK does not own `AIAgent.RunStreamingAsync(...)`, `ChatClientAgentThread`, `ChatMessageStoreFactory`, or the policy for mapping an AG-UI thread id to a persisted agent thread.

## Proposal (once MAF consumes our packages)

1. In MAF `MapAGUI`, after `input.ToChatRequestContext(...)`, read `ctx.Input.ThreadId` and resolve an `AgentThread` from MAF's configured session/thread store.
2. Pass that `AgentThread` to `AIAgent.RunStreamingAsync(...)` instead of passing or defaulting to `null`.
3. Make the AG-UI thread id available before constructing the `ChatMessageStore`, either through a thread factory parameter or a MAF session abstraction, not through `AsyncLocal`.
4. Continue also passing `ctx.ChatOptions`, which contains `AGUIConstants.RunAgentInputKey`, so tools and middleware can inspect the original AG-UI input when needed.
