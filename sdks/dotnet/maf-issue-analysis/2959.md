# Issue #2959 — Azure AI Projects agent-mode ignores per-request AG-UI tools

- Repo: microsoft/agent-framework · [issue #2959](https://github.com/microsoft/agent-framework/issues/2959)
- Category: **AF-specific** — proposal for once MAF consumes our packages

## Summary

The issue reports that Azure AI Projects agent-mode silently drops tools supplied per request through AG-UI / `ChatOptions.Tools`. As a result, AG-UI frontend tools are unusable unless they were baked into the server-side Azure AI Projects agent definition.

## What our packages already provide

AG-UI tool definitions arrive on `RunAgentInput.Tools` (`src\AGUI.Abstractions\Context\RunAgentInput.cs:38`-`43`). `ToChatRequestContext` converts those to MEAI `AITool`s (`src\AGUI.Hosting.AspNetCore\RunAgentInputExtensions.cs:48`-`49`) and installs them on `ChatOptions.Tools` (`src\AGUI.Hosting.AspNetCore\RunAgentInputExtensions.cs:181`-`192`). On the client side, `AGUIChatClient` also converts MEAI `options.Tools` into `RunAgentInput.Tools` when building the AG-UI request (`src\AGUI.Client\AGUIChatClient.cs:392`-`396`).

## What remains MAF-side

Azure AI Projects agent-mode controls which `ChatOptions` are considered overridable and what is sent to the service. Our AG-UI SDK cannot force that MAF client to union per-request tools into an Azure AI Projects run, nor can it decide whether agent-mode should reject unsupported tool augmentation.

## Proposal (once MAF consumes our packages)

1. In MAF's Azure AI Projects agent-mode client, inspect `ChatOptions.Tools` after `MapAGUI` has produced `ctx.ChatOptions`.
2. Choose a behavior explicitly: either support per-request tool augmentation by unioning `ChatOptions.Tools` into the Azure AI Projects request, or reject it.
3. If rejecting, detect `ChatOptions.Tools.Count > 0` and throw/log a clear error that Azure AI Projects agent-mode does not support AG-UI frontend tools and requires tools to be configured on the server-side agent/version.
4. Add an AG-UI endpoint regression test that supplies a frontend tool and verifies either that the Azure AI Projects request includes it or that the endpoint returns the strict diagnostic.
