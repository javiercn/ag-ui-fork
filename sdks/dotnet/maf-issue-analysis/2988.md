# Issue #2988 — Support dynamic agent resolution in AG-UI endpoints

- Repo: microsoft/agent-framework · [issue #2988](https://github.com/microsoft/agent-framework/issues/2988)
- Category: **AF-specific** — proposal for once MAF consumes our packages

## Summary

The issue asks for `MapAGUI` to resolve an `AIAgent` dynamically per request, for example from `/agents/{agentId}/stream`, tenant data, or a database. The current MAF API accepts a pre-created `AIAgent`, which forces users to reimplement AG-UI request/response handling for dynamic routing.

## What our packages already provide

The AG-UI request type is public as `RunAgentInput` (`src\AGUI.Abstractions\Context\RunAgentInput.cs:11`-`17`). The hosting package exposes the generic endpoint building blocks: `ToChatRequestContext(...)` adapts a `RunAgentInput` to MEAI messages and `ChatOptions` (`src\AGUI.Hosting.AspNetCore\RunAgentInputExtensions.cs:40`-`49`, `src\AGUI.Hosting.AspNetCore\RunAgentInputExtensions.cs:91`-`108`), and `AsAGUIEventStreamAsync(...)` converts a `ChatResponseUpdate` stream back to AG-UI events (`src\AGUI.Hosting.AspNetCore\ChatResponseUpdateAGUIExtensions.cs:29`-`39`).

## What remains MAF-side

Agent lookup is a MAF hosting concern. Our SDK does not own MAF's `MapAGUI` overload set, keyed `AIAgent` registration, route-value parsing, authorization, multi-tenant configuration, or fallback behavior when an agent is missing.

## Proposal (once MAF consumes our packages)

1. Add a MAF overload such as `MapAGUI(string pattern, Func<HttpContext, CancellationToken, ValueTask<AIAgent?>> agentFactory)`.
2. In that overload, bind the body as public `AGUI.Abstractions.RunAgentInput`, call `input.ToChatRequestContext(jsonOptions, streamOptions)`, and only then resolve the `AIAgent` from `HttpContext`/route/tenant data.
3. Invoke the resolved agent with `ctx.Messages` and `ctx.ChatOptions`, then stream `updates.AsAGUIEventStreamAsync(ctx, cancellationToken)` as SSE.
4. Return `404` or another explicit problem response when the factory returns `null`; do not hide dynamic resolution failures behind an empty AG-UI stream.
