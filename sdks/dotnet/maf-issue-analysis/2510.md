# Issue #2510 — Sync AG-UI conversation history from backend

- Repo: microsoft/agent-framework · [issue #2510](https://github.com/microsoft/agent-framework/issues/2510)
- Category: **Integration-pkg — already fixed/covered**

## Summary
The issue asks for backend conversation history sync via AG-UI `MESSAGES_SNAPSHOT` events, plus a way to emit those protocol events directly.

## Fix in our SDK
`MessagesSnapshotEvent` is a public `BaseEvent` whose `Type` is `AGUIEventTypes.MessagesSnapshot` and whose `Messages` property carries the conversation history (`src/AGUI.Abstractions/Events/MessagesSnapshotEvent.cs:7-13`). The discriminator constant is present (`src/AGUI.Abstractions/Events/AGUIEventTypes.cs:34`), the source-generated serializer includes it (`src/AGUI.Abstractions/Serialization/AGUIJsonSerializerContext.cs:70`), and polymorphic `BaseEvent` serialization/deserialization handles it (`src/AGUI.Abstractions/Events/BaseEventJsonConverter.cs:53`, `src/AGUI.Abstractions/Events/BaseEventJsonConverter.cs:144-145`).

## Validating test
Added (pending central run): `tests/AGUI.Abstractions.UnitTests/MafIssueFixedTests_2510.cs:10` (`MessagesSnapshotEvent_SerializesAndDeserializesViaBaseEvent`) validates the `MESSAGES_SNAPSHOT` JSON shape and `BaseEvent` round-trip.

## Notes
MAF can emit backend history by constructing `MessagesSnapshotEvent` from `AGUI.Abstractions`; no private MAF event type is required.
