# Issue #2081 — Intermediate state from tools for AG-UI

- Repo: microsoft/agent-framework · [issue #2081](https://github.com/microsoft/agent-framework/issues/2081)
- Category: **Deprecated-workaround** — use the now-public AG-UI events

## Summary

The issue asks how a deep-research agent can stream intermediate AG-UI state updates while a `perform_research` tool is running. The example attempted to yield MEAI `DataContent(stateBytes, "application/json")` from the tool and rely on the old AG-UI hosting transport to reinterpret that JSON as `STATE_SNAPSHOT`. That also made the payload look like normal tool output/text instead of a first-class AG-UI state event.

## Why the old approach is deprecated

The `DataContent("application/json")` → `STATE_*` smuggling existed because the MAF AG-UI event types were internal (#2558), so user code could not create the protocol event directly. In this SDK, `StateSnapshotEvent`, `StateDeltaEvent`, `CustomEvent`, and `RawEvent` are public in `AGUI.Abstractions`. `ChatResponseUpdateAGUIExtensions.AsAGUIEventStreamAsync` also streams any `BaseEvent` assigned to `ChatResponseUpdate.RawRepresentation` directly, so state should be emitted as the proper AG-UI event rather than disguised as MEAI content.

## New approach — sample

```csharp
using System.Runtime.CompilerServices;
using System.Text.Json;
using System.Text.Json.Serialization;
using AGUI.Abstractions;
using AGUI.Hosting.AspNetCore;
using Microsoft.Extensions.AI;

internal sealed class ResearchStateChatClient : DelegatingChatClient
{
    private readonly JsonSerializerOptions _jsonSerializerOptions;

    public ResearchStateChatClient(IChatClient innerClient, JsonSerializerOptions jsonSerializerOptions)
        : base(innerClient)
    {
        _jsonSerializerOptions = jsonSerializerOptions;
    }

    public override async IAsyncEnumerable<ChatResponseUpdate> GetStreamingResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        [EnumeratorCancellation] CancellationToken cancellationToken = default)
    {
        var state = ReadState(options) ?? new AgentStateSnapshot();
        var searchIndex = state.Searches.Count;
        state.Searches.Add(new SearchInfo { Query = "latest AG-UI state patterns", Status = "InProgress" });

        yield return new ChatResponseUpdate
        {
            RawRepresentation = new StateSnapshotEvent
            {
                Snapshot = JsonSerializer.SerializeToElement(state, _jsonSerializerOptions)
            }
        };

        await foreach (var update in base.GetStreamingResponseAsync(messages, options, cancellationToken).ConfigureAwait(false))
        {
            yield return update;
        }

        yield return new ChatResponseUpdate
        {
            RawRepresentation = new StateDeltaEvent
            {
                Delta = JsonSerializer.SerializeToElement(new[]
                {
                    new { op = "replace", path = $"/searches/{searchIndex}/status", value = "Done" }
                }, _jsonSerializerOptions)
            }
        };
    }

    private AgentStateSnapshot? ReadState(ChatOptions? options)
    {
        if (options?.AdditionalProperties?.TryGetValue(AGUIConstants.RunAgentInputKey, out var inputObj) is true
            && inputObj is RunAgentInput input
            && input.State is { ValueKind: JsonValueKind.Object } state)
        {
            return state.Deserialize<AgentStateSnapshot>(_jsonSerializerOptions);
        }

        return null;
    }
}

internal sealed class AgentStateSnapshot
{
    [JsonPropertyName("searches")]
    public List<SearchInfo> Searches { get; set; } = [];
}

internal sealed class SearchInfo
{
    [JsonPropertyName("query")]
    public string Query { get; set; } = string.Empty;

    [JsonPropertyName("status")]
    public string Status { get; set; } = string.Empty;
}
```

## Notes

Do **not** port the `DataContent("application/json")` → `STATE_*` magic mapping into the new packages. That would re-introduce the workaround and make state updates depend on content-shape heuristics instead of explicit public AG-UI protocol events.
