# Issue #4177 — Auto-bridge StateBag mutations to AG-UI state events

- Repo: microsoft/agent-framework · [issue #4177](https://github.com/microsoft/agent-framework/issues/4177)
- Category: **AF-specific** — proposal for once MAF consumes our packages

## Summary
The issue asks for automatic `STATE_SNAPSHOT`/`STATE_DELTA` emission from MAF `AgentSession.StateBag` mutations and predictive state deltas during tool-argument streaming. Today developers must manually emit state events from samples or middleware.

## What our packages already provide
- Public AG-UI state event types exist: `StateSnapshotEvent` carries a full JSON snapshot and `StateDeltaEvent` carries RFC 6902-style JSON patch data (`sdks/dotnet/src/AGUI.Abstractions/Events/StateSnapshotEvent.cs:10`, `sdks/dotnet/src/AGUI.Abstractions/Events/StateSnapshotEvent.cs:19`, `sdks/dotnet/src/AGUI.Abstractions/Events/StateDeltaEvent.cs:10`, `sdks/dotnet/src/AGUI.Abstractions/Events/StateDeltaEvent.cs:19`).
- These types are included in the AOT serializer context and polymorphic `BaseEvent` converter (`sdks/dotnet/src/AGUI.Abstractions/Serialization/AGUIJsonSerializerContext.cs:57`, `sdks/dotnet/src/AGUI.Abstractions/Serialization/AGUIJsonSerializerContext.cs:58`, `sdks/dotnet/src/AGUI.Abstractions/Events/BaseEventJsonConverter.cs:40`).
- `AsAGUIEventStreamAsync` emits any `BaseEvent` placed in `ChatResponseUpdate.RawRepresentation` directly (`sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:65`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:82`).
- Tool result/call mapping helpers can emit state events for explicit mappings (`sdks/dotnet/src/AGUI.Hosting.AspNetCore/AGUIStreamOptions.cs:91`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/AGUIStreamOptions.cs:101`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/AGUIStreamOptions.cs:113`).

## What remains MAF-side
The deprecated workaround of sending `DataContent("application/json")` to trigger `STATE_SNAPSHOT` is superseded: MAF should emit `StateSnapshotEvent` or `StateDeltaEvent` directly via `ChatResponseUpdate.RawRepresentation`. Our SDK does not own MAF `StateBag`, change tracking, JSON-patch diffing, or workflow/tool-argument streaming internals.

## Proposal (once MAF consumes our packages)
1. In MAF's AG-UI hosting integration, emit an initial `StateSnapshotEvent` from `AgentSession.StateBag` at run start using `ChatResponseUpdate.RawRepresentation`.
2. Wrap or observe `StateBag.SetValue<T>()` while serving AG-UI requests and emit `StateDeltaEvent` JSON Patch entries for each mutation.
3. For predictive updates, add a MAF workflow/tool-argument observer that converts partial tool arguments into configured state-path deltas and emits `StateDeltaEvent` directly.
4. Keep `AGUIStreamOptions.MapResultAsStateSnapshot/MapResultAsStateDelta` for app-specific tool mappings, but provide the StateBag bridge as the out-of-box MAF path.
