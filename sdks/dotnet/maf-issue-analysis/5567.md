# Issue #5567 — BaseEventJsonConverter.Read is missing StateDeltaEvent mapping

- Repo: microsoft/agent-framework · [issue #5567](https://github.com/microsoft/agent-framework/issues/5567)
- Category: **Integration-pkg — already fixed/covered**

## Summary
The issue reports that deserializing a `BaseEvent` with `"type":"STATE_DELTA"` throws `JsonException: Unknown BaseEvent type discriminator: 'STATE_DELTA'` because the read-side discriminator switch lacks a `StateDeltaEvent` case.

## Fix in our SDK
`src\AGUI.Abstractions\Events\BaseEventJsonConverter.cs:40-41` maps the `STATE_SNAPSHOT` and `STATE_DELTA` discriminators on read:

```csharp
AGUIEventTypes.StateSnapshot => jsonElement.Deserialize(options.GetTypeInfo(typeof(StateSnapshotEvent))) as StateSnapshotEvent,
AGUIEventTypes.StateDelta => jsonElement.Deserialize(options.GetTypeInfo(typeof(StateDeltaEvent))) as StateDeltaEvent,
```

The write side is also symmetric at `src\AGUI.Abstractions\Events\BaseEventJsonConverter.cs:105-110`.

## Validating test
Existing tests cover this:

- `tests\AGUI.Abstractions.UnitTests\StateDeltaEventTest.cs:55-65`, method `Deserialize_ViaBaseEvent_ReturnsCorrectType`, deserializes `{"type":"STATE_DELTA",...}` through `AGUIJsonSerializerContext.Default.BaseEvent` and asserts `StateDeltaEvent`.
- `tests\AGUI.Abstractions.UnitTests\Compatibility\StateEventsCompatibilityTest.cs:52-63`, method `StateDelta_Basic_DeserializesFromTypeScriptPayload`, validates TypeScript fixture compatibility through the base event path.

## Notes
MAF inherits this fix by consuming `AGUI.Abstractions`; the polymorphic base event converter already recognizes `STATE_DELTA` on read and write.
