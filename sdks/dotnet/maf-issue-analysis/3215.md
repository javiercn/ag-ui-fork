# Issue #3215 — Copilot Studio activities are dropped by AG-UI integration

- Repo: microsoft/agent-framework · [issue #3215](https://github.com/microsoft/agent-framework/issues/3215)
- Category: **AF-specific** — proposal for once MAF consumes our packages

## Summary
Copilot Studio agents produce valid `Activity` messages, suggested actions, and streaming chunks, but the AG-UI SSE output contains only `RUN_STARTED` and `RUN_FINISHED`. The issue points to MAF's Copilot Studio activity processing dropping or failing to translate the relevant activities before the AG-UI converter sees them.

## What our packages already provide
- If MAF yields MEAI `TextContent`, `AsAGUIEventStreamAsync` emits AG-UI text message start/content/end events (`sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:130`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:145`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:152`).
- The protocol includes activity event types for richer activity snapshots/deltas (`sdks/dotnet/src/AGUI.Abstractions/Events/AGUIEventTypes.cs:30`, `sdks/dotnet/src/AGUI.Abstractions/Serialization/AGUIJsonSerializerContext.cs:66`).
- MAF-specific content can be mapped to AG-UI events with `AGUIStreamOptions.MapContent(...)`, and raw `BaseEvent` instances can be emitted through `ChatResponseUpdate.RawRepresentation` (`sdks/dotnet/src/AGUI.Hosting.AspNetCore/AGUIStreamOptions.cs:59`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:65`).

## What remains MAF-side
Our SDK does not know Bot Framework/Copilot Studio `Activity` semantics, suggested actions, or the MAF `ActivityProcessor`. MAF must convert accepted Copilot Studio activities into MEAI text/content updates or directly into AG-UI events before reaching the hosting converter.

## Proposal (once MAF consumes our packages)
1. Update MAF's Copilot Studio `ActivityProcessor` to preserve `type = "message"` and streaming activities instead of filtering them out.
2. Map activity text/chunks to `ChatResponseUpdate` with `TextContent`; the SDK will emit `TEXT_MESSAGE_*` events.
3. Map `suggestedActions` to an AG-UI representation MAF owns (for example `CustomEvent`, `ActivitySnapshotEvent`, or input-request interrupts) and emit via `RawRepresentation` or `AGUIStreamOptions.MapContent`.
4. Add Copilot Studio + AG-UI tests verifying text, streaming chunks, and suggested actions all appear in SSE.
