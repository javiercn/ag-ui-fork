# Issue #3011 — DevUI cannot resolve named handoffs workflow

- Repo: microsoft/agent-framework · [issue #3011](https://github.com/microsoft/agent-framework/issues/3011)
- Category: **AF-specific** — proposal for once MAF consumes our packages

## Summary
A handoffs workflow registered as `HandoffsTutorWorkflow` fails in DevUI because the workflow factory returns a workflow with an empty name while DevUI expects the registered name. This blocks testing handoff workflows through DevUI.

## What our packages already provide
- Our hosting package adapts an AG-UI request into MEAI messages/options via `RunAgentInputExtensions.ToChatRequestContext(...)` (`sdks/dotnet/src/AGUI.Hosting.AspNetCore/RunAgentInputExtensions.cs:40`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/RunAgentInputExtensions.cs:48`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/RunAgentInputExtensions.cs:101`).
- It emits AG-UI lifecycle events around whatever MEAI stream MAF supplies (`sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:86`, `sdks/dotnet/src/AGUI.Hosting.AspNetCore/ChatResponseUpdateAGUIExtensions.cs:376`).
- It does not register, name, resolve, or validate MAF workflows/agents.

## What remains MAF-side
MAF owns `AddWorkflow`, `AddAsAIAgent`, DevUI agent resolution, and workflow factory name validation. The mismatch between the DI registration key and the constructed workflow name must be fixed in MAF's workflow/DevUI integration.

## Proposal (once MAF consumes our packages)
1. In MAF workflow registration, ensure the `key` passed to the factory is applied to the workflow metadata/name when the builder returns an unnamed workflow.
2. In `AddAsAIAgent`/DevUI resolution, use a single canonical agent id/name and avoid comparing against an empty workflow name.
3. Once resolved, run the handoff workflow through the AG-UI endpoint by converting `RunAgentInput` with `ToChatRequestContext(...)` and streaming with `AsAGUIEventStreamAsync(...)`.
4. Add a DevUI test that registers a handoffs workflow by name, starts the service, and verifies the agent appears and can be invoked.
