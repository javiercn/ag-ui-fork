# Issue #2558 — Support more AG-UI event types

- Repo: microsoft/agent-framework · [issue #2558](https://github.com/microsoft/agent-framework/issues/2558)
- Category: **Integration-pkg — already fixed/covered**

## Summary
The issue tracks missing AG-UI protocol event types beyond the original run, text, tool, and state set: `STEP_STARTED`, `STEP_FINISHED`, `MESSAGES_SNAPSHOT`, `ACTIVITY_SNAPSHOT`, `ACTIVITY_DELTA`, `RAW`, and `CUSTOM`.

## Fix in our SDK
Our SDK exposes these event types in `AGUI.Abstractions` and wires them into polymorphic serialization:

- Event type constants include the expanded protocol set at `src\AGUI.Abstractions\Events\AGUIEventTypes.cs:12-34`.
- `BaseEventJsonConverter.Read` recognizes `STEP_*`, `ACTIVITY_*`, `CUSTOM`, `RAW`, and `MESSAGES_SNAPSHOT` at `src\AGUI.Abstractions\Events\BaseEventJsonConverter.cs:31-53`.
- `BaseEventJsonConverter.Write` serializes those same concrete event types at `src\AGUI.Abstractions\Events\BaseEventJsonConverter.cs:78-145`.
- `AGUIJsonSerializerContext` registers the concrete types for source generation at `src\AGUI.Abstractions\Serialization\AGUIJsonSerializerContext.cs:15-70`.
- Example concrete types include `MessagesSnapshotEvent` at `src\AGUI.Abstractions\Events\MessagesSnapshotEvent.cs:7-13`, `ActivitySnapshotEvent` at `src\AGUI.Abstractions\Events\ActivitySnapshotEvent.cs:10-39`, and `RawEvent` at `src\AGUI.Abstractions\Events\RawEvent.cs:10-27`.
